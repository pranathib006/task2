## 📊 Task 02 - Titanic EDA Dashboard

### 📌 Project Overview

This project focuses on analyzing the **Titanic Dataset** using **Power BI** to explore survival patterns based on passenger demographics such as **Sex**, **Passenger Class (Pclass)**, and **Age**.

The analysis helps identify which groups of passengers had higher survival rates and uncovers key patterns in the Titanic disaster data through interactive visualizations.

---

### 🎯 Objectives

- Visualize survival distribution among Titanic passengers
- Analyze survival rates by **Sex** (male vs female)
- Explore survival counts by **Passenger Class** (1st, 2nd, 3rd)
- Study **Age distribution** of passengers
- Build an interactive **Power BI EDA Dashboard**

---

### 🛠️ Tools & Technologies Used

| Tool | Purpose |
|------|---------|
| Power BI | Dashboard Creation & Visualization |
| Titanic Dataset | Source Data (891 passengers) |
| Data Cleaning | Handling missing values & transformation |
| Data Visualization | Charts, Graphs & Interactive Filters |
| Dashboard Design | Layout & Storytelling |
| Business Intelligence | Insight Extraction |

---

### 📈 Key Insights

- 👩 **Females had significantly higher survival rates** than males
- 🎫 **1st Class passengers** survived more than 2nd and 3rd class
- 💀 **549 passengers (61.62%)** did not survive
- ✅ **342 passengers (38.38%)** survived
- 👦 **Most passengers were aged between 20–35 years**
- 📉 Classic **right-skewed age distribution** observed

---

### 📊 Charts Created

| Chart | Type | Description |
|-------|------|-------------|
| Count of PassengerId by Survived | Pie Chart | Shows 61.62% not survived vs 38.38% survived |
| Sum of Survived by Sex | Horizontal Bar Chart | Females survived more than males |
| Sum of Survived by Pclass | Horizontal Bar Chart | 1st class had highest survival |
| Count of PassengerId by Age | Histogram / Area Chart | Age distribution with peak at ~28 years |

### 📢 Conclusion

**🚢 Understanding Titanic Survival Patterns — Key Insights from Data**

After analyzing the Titanic dataset through four powerful visualizations, here's what the data reveals:

🥧 **The Pie Chart tells us:**
Only **38.38% of passengers survived** — a stark reminder of the scale of the tragedy. More than 6 out of 10 passengers did not make it.

📊 **The Bar Chart (by Sex) tells us:**
**Women survived at nearly double the rate of men**, reflecting the "women and children first" evacuation protocol followed during the disaster.

📊 **The Bar Chart (by Pclass) tells us:**
**1st Class passengers had the highest survival count**, suggesting socioeconomic status played a significant role in access to lifeboats.

📈 **The Age Histogram tells us:**
The **majority of passengers were young adults (20–35 years)**. The distribution is **right-skewed**, with a sharp peak around age 28 and a long tail toward older ages.
